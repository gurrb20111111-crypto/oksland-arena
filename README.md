# 옥정섬 SOS · 클리어 아레나 (교실용 실시간 대전 서버)

옥정섬 SOS를 클리어한 학생들이 한 섬에 모여 몬스터를 잡고 서로 겨루는 실시간 대전입니다.
서버(이 폴더)는 **선생님 컴퓨터**나 **무료 클라우드**에서 실행하고, 학생은 태블릿 브라우저로 접속합니다.
필요한 것은 Node.js 하나뿐이며, `npm install`은 하지 않아도 됩니다.

## 1. 선생님 컴퓨터에서 실행하기 (같은 와이파이)

1. Node.js 준비
   - 설치할 수 있으면: https://nodejs.org 에서 **LTS** 버전을 설치합니다.
   - 설치 권한이 없으면: 같은 사이트의 **Windows Binary (.zip)** 를 받아 압축을 풀고, 그 안의 `node.exe`를 이 폴더(server.js 옆)에 복사합니다.
2. 이 폴더의 **`start-windows.bat`** 을 더블클릭합니다. (맥: `start-mac.command`)
   - Windows 방화벽 창이 뜨면 **허용**(개인 네트워크)을 누릅니다.
3. 검은 창에 나온 내용을 확인합니다.
   - `학생 접속 주소` 예: `http://192.168.0.10:3000`
   - `관리자 비밀번호` 예: `a1b2c3`
4. 교실 TV(선생님 컴퓨터) 브라우저에서 `학생 접속 주소/admin` 을 열고 비밀번호를 넣으면 **실시간 순위판·관리 화면**이 나옵니다.
5. 끝나면 검은 창을 닫거나 `Ctrl + C`.

> 수업 전에 태블릿 한 대로 학생 접속 주소가 열리는지 꼭 확인하세요.
> 학교 무선망은 기기끼리의 통신을 막아 두는 경우가 있습니다(교사 PC가 유선망이거나 '클라이언트 격리'가 켜진 경우).
> 열리지 않으면 ① 선생님 노트북을 학생과 같은 와이파이에 연결하거나, ② 휴대용 공유기/핫스팟을 쓰거나, ③ 아래 클라우드 방법을 쓰세요.

## 2. 무료 클라우드에 올리기 (어디서나 접속)

Render(https://render.com) 예시:
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → New → **Web Service** → 저장소 선택.
3. Runtime: Node · Build Command: 비워 두기 · Start Command: `node server.js`
4. Environment에 `ADMIN_KEY` = 원하는 관리자 비밀번호를 추가합니다.
5. 배포가 끝나면 `https://○○○.onrender.com` 이 학생 접속 주소, 뒤에 `/admin` 이 관리 화면입니다.
- 무료 요금제는 한동안 접속이 없으면 잠들어서, 첫 접속에 1분 정도 걸릴 수 있습니다. 수업 시작 전에 한 번 열어 두세요.

## 3. 옥정섬 SOS 게임과 연결하기

게임 링크 끝에 아레나 주소를 붙여 학생에게 나눠 주면, 클리어 화면에 **[클리어 아레나 입장]** 버튼이 생깁니다.

```
…게임 링크…#few&arena=192.168.0.10:3000
…게임 링크…#arena=https://○○○.onrender.com
```
(몬스터 설정이 없으면 `#arena=…` 만 써도 됩니다. 게임의 도움말 → '아레나 주소' 칸에 직접 적어도 됩니다.)

버튼이 없어도 학생은 TV에 띄운 주소로 들어가 **클리어 화면의 이름과 입장 코드(4자리)** 를 적으면 됩니다.
코드는 이름과 날짜로 만들어져서, 게임을 클리어한 학생만 알 수 있습니다. 관리 화면에서 코드 확인을 끄면 누구나 들어올 수 있습니다.

## 3-1. 아레나 두 개 (1부 대결 / 2부 협동)

| 아레나 | 학생 주소 | TV 관리 화면 | 입장 코드 | 내용 |
|---|---|---|---|---|
| **1부 대결** | `주소/` | `주소/admin` | 1부 CLEAR 화면의 코드 | 원래 방식: 개인전 PvP(팀전은 관리 화면에서 켤 수 있음), 왕관·현상금, 상점. 접속자 절반이 Lv 10 이상이면 레이드 보스 등장 |
| **2부 협동** | `주소/2` | `주소/admin2` | 2부 CLEAR(ALL CLEAR) 화면의 코드 (1부 코드와 다름) | 모두가 한편(서로 공격 안 됨). **들어온 순서대로 3~4명이 한 팀**(아래 2부 팀 미션) |

- 두 아레나는 같은 서버에서 따로 돌아가요(기록·몬스터·보스 따로).
- **선생님(운영자) 입장**: 입장 코드 칸에 관리자 비밀번호(ADMIN_KEY)를 넣으면 날짜와 상관없이 들어가고 **Lv 100 운영자**가 돼요(최고 장비, 9999코인, 부품 99, 이름표 🛡 운영자). 학생 순위·왕관·보스 체력·퀘스트 목표 계산에서는 빠지고, 쓰러져도 잃는 것이 없어요. 이동 속도는 Lv 15 기준(+15%).
- 레이드 보스 **태풍 마수 돌개**: 체력 5000 + 9000×접속 인원. 내려찍기(근접), 빨간 원(1.3초 뒤 큰 회오리 + 밀쳐내기), 노란 원(1.4초 뒤 여러 명에게 낙뢰), 체력 60%·30%에서 부하 소환, 30% 아래 분노(더 빠름). 쓰러뜨리면 공격한 모두가 기여도만큼 코인 + 레벨 업(2부는 부품 ⚙3). 관리 화면 [태풍 마수 돌개 소환]으로 언제든 부를 수 있음.
- 몬스터 10종: 매연 달팽이 · 스모그 슬라임 · 미세먼지 벌 · 매연 멧돼지(돌진) · 스모그 골렘 + **회오리 족제비**(아주 빠르게 휙 돌진) · **매연 대포꽃**(멀리서 매연탄을 쏨) · **녹슨 집게게**(받는 피해 40% 감소) · **연기 박쥐**(3마리씩 떼로) · **강철 매연거북**(느리지만 노란 원 1초 뒤 한 방 48). 최대 레벨 15.


### 2부 팀 미션 (2026-10-18)
- **팀 편성**: 들어온 순서대로 채움. 3명이 모이면 팀 미션 시작, 4번째는 진행 중에 합류, 5번째부터 새 팀. 2명만 2분(`SQ_WAIT` 환경 변수, ms) 넘게 기다리면 2명이 먼저 출발. 혼자 남은 친구는 자리가 빈 팀에 자동 합류. 팀 이름·색: 바람·태양·바다·번개·구름·파도·별빛·무지개·소나무·등대·반딧불·돌고래.
- **팀원 모이기 전 = 혼자 훈련**: 돌풍 발전기 풍력 문제 2개 · 과제 1개 · 몬스터 4마리(단계마다 +2, 최대 10) → 경험치 + 40코인 + 부품 ⚙2 + 회복 음료, 단계가 계속 이어짐.
- **팀 미션 4단계** (단계마다 팀원 모두 레벨 업 + 40코인 + 부품 ⚙1):
  1. 🔧 분담 수리: 과제 기계 과제 인원×2개, **팀원 모두 1개 이상**(기록은 이름으로 — 나갔다 다시 들어와도 같은 팀·✔ 유지). 한 친구가 끝까지 못 해도 목표의 2배를 채우면 통과. 돌풍 발전기 문제는 미션 ①에 안 들어감(맞히면 안내).
  2. 📘 릴레이 풍력 퀴즈: 팀 모두 한 풍력발전기(9m 안)에 모여 E → 한 명씩 돌아가며 5문제(20초), 4개 이상 정답. 안 모였으면 팀원 미니맵에 노란 집합 신호.
  3. 🌫 함께 매연 정화: 몬스터 인원×5마리, **팀원 15m 안**에서 잡아야 인정
  4. ⚡ 동시 가동: 팀 모두 발전기에 모여 E → 각자 다른 문제를 동시에, 모두 맞혀야 성공
  - 실패하면 15초 뒤 재도전. 문제 푸는 동안 팀원은 무적.
  - 🏆 팀 CLEAR: 추가 60코인 + 부품 ⚙2 + 바람의 축복 60초, CLEAR 순위 표시. 미션 중인 팀의 절반 이상이 CLEAR하면 태풍 마수 돌개 등장(토벌 후 4분 쉼).
- ⏱ 팀 시간(2026-10-20): 팀 결성부터 재기 시작 → 미션 바에 경과 시간, 미션 성공 때 그 미션에 걸린 시간, CLEAR 때 총 시간·미션별 시간(①~④). 순위(Tab) 창·관리 화면 팀 칸에 시간, 관리 화면에 'CLEAR 기록(걸린 시간 순)'. [팀 미션 처음부터]는 시간도 0부터.
- 관리 화면(admin2): [모으는 중인 팀 바로 출발] · [모든 팀 다음 미션으로] · [팀 미션 처음부터] · [들어온 순서대로 다시 나누기](지금 학생들을 3~4명씩 균등하게).

## 3-2. 섬 구조물 · 상점 4곳 · 전직 · 타격감 · 보물 상자 · 바다 낙사 (2026-10-15)

- **올라갈 수 있는 곳**: 전망대(높이 5, 계단+사다리) · 정비 데크(3.2, 계단+사다리) · 바위 고원(2.6, 경사로+사다리) · 감시탑(6.5, 사다리만) · 컨테이너(2.6 → 사다리로 높은 컨테이너 5.2). 계단·사다리 쪽으로 걸어가면 올라가고, 가장자리 밖으로 걸으면 뛰어내려요.
  - 높이가 다르면 **근접 공격(바람 펀치·회오리·몬스터 물기·거북 내려찍기)이 닿지 않아요** → 도망칠 수 있어요.
  - 날아다니는 몬스터(벌·박쥐)와 **원거리 공격(돌풍 대포·낙뢰·토네이도·대포꽃 매연탄·궁수 화살·보스 낙뢰)** 은 높이와 상관없이 맞아요. 보스의 빨간 원(회오리 강타)은 땅에 있는 사람만 맞아요.
- **몬스터 수**: 동시에 최대 55마리(8 + 접속 인원×2.8), 0.6초마다 생겨요(2026-10-15 수업에서 렉이 심해 110마리 → 다시 55마리). 학생 화면에는 40m 안 몬스터만 자세히 보내고 먼 몬스터는 미니맵 점으로만 보여요. 수를 바꾸려면 Render Environment에 `MON_CAP`(최대 수)·`MON_PER`(학생 1명당) 값을 넣으면 돼요.
- **가볍게 그리기**: 멀리 있는 친구·몬스터는 그리지 않고, 멀리서 난 피해 숫자·효과는 건너뛰고, 피해 숫자 그림은 다시 써요(태블릿 렉 줄이기).
- **바람상회 4곳**: 동(33, 0) · 서 · 남 · 북. 노란 원(반지름 5.5) 안에서 `B`. 미니맵 노란 네모.
- **바람의 신전(섬 가운데)**: Lv 5부터 `J`로 **전직**(처음 무료, 바꾸면 100코인). 직업 스킬은 3-6 참고.
  - 🗡 바람 검사: 체력 +30%, 받는 피해 −10%, 바람 펀치 +30%, 세게 밀쳐냄, 덜 밀림
  - 🏹 돌풍 궁수: 바람 펀치가 9m 날아가는 화살, 이동 속도 +8%
  - 🔮 번개 마법사: 스킬 피해 +35%, 스킬 대기 −15%, 체력 −10%
  - 💚 치유 정령사: 재충전(스킬 4)이 주변 7m 친구(같은 팀·2부는 모두)도 30% 회복, 체력 회복 2배, 펀치 −10%
- **타격감**: 맞으면 뒤로 밀려요(멧돼지·골렘·거북·보스는 더 세게, 건물 벽은 통과 못 함). 맞은 대상이 번쩍이고, 큰 피해 숫자는 노랗고 크게, 내가 맞으면 화면이 흔들려요. 몬스터는 맞으면 잠깐 멈칫해요.
- **🎁 보물 상자 이벤트**: 2분 30초마다(첫 상자는 45초 뒤) 섬 어딘가에 빛기둥과 함께 상자가 떨어져요(35%는 건물 꼭대기). 미니맵에 금색 별. 떨어진 뒤 60초 안에 열지 않으면 사라져요.
  - 상자 옆에서 `E`(또는 [상자 열기])를 누르고 **3초 버티기**. 그동안 맞거나 멀어지면 끊겨요 → 다른 팀이 방해하러 몰려듦. 한 번에 한 명만 열 수 있어요.
  - 보상: 코인 90~150 · 아직 최고가 아닌 장비 하나 +1단계 · 회복 음료 +1 · 체력 가득(2부는 부품 ⚙3 추가). 섬 전체에 누가 열었는지 알려줘요.
  - 관리 화면 **[🎁 보물 상자 떨어뜨리기]** 로 선생님이 바로 떨어뜨릴 수도 있어요.
- **🌊 바다로 밀어 떨어뜨리기**: 섬 가장자리 해변(가운데에서 55m 바깥)에서 맞으면 1.8배 더 멀리 밀리고, 바다까지 밀리면 풍덩!
  - 1부: 바다에 빠지면 쓰러짐(민 사람이 처치한 것으로, 6초 안에 때린 사람이 있으면 그 사람). 2부: 섬으로 건져 올리고 체력 −25%만.
  - 몬스터(벌·박쥐 제외)도 바다로 밀면 바로 정화 + 보상. 처음 해변에 들어가면 안내가 한 번 떠요.

## 3-3. 안전 쇼핑 · 따라잡기 (2026-10-15)

- **🛒 안전 쇼핑**: 바람상회 노란 원 안에서 `B`(상점 버튼)를 누르면 **10초 동안 공격받지 않아요**. 대신 그동안 공격·과제·보물 상자는 못 해요. 10초가 지나거나 원 밖으로 나가면 자동으로 상점이 닫히고(나온 뒤 1초 보호), **10초 동안 다시 못 들어가요**(무적 악용 방지). 쇼핑 중인 사람은 **반투명 유령 + 금색 원 + '🛒 쇼핑 중'** 이름표로 보여요. 몬스터는 상점 원 안에 들어오지 못해요.
- **🚀 따라잡기 출발**: 친구들(2명 이상)이 이미 있으면 늦게 온 사람은 **평균 레벨의 60%** 로 시작하고, 레벨만큼 코인과 기본 장비(무기·갑옷 최대 2단계)를 받아요.
- **🔥 경험치 부스트**: 레벨이 평균보다 1.5 이상 낮으면 몬스터·과제·처치 경험치가 **최대 3배**(차이 1당 +25%). HUD에 '🔥 경험치 ×N' 표시.
- **⚖ 레벨 차이 보정(학생끼리)**: 높은 레벨이 낮은 레벨을 때리면 피해가 1레벨당 5%씩 줄고(최대 −40%), 낮은 레벨이 높은 레벨을 때리면 5%씩 늘어요(최대 +50%).
- **🛡 약자 보호**: 5레벨 이상 높은 사람에게 쓰러지면 코인 10%만 잃고, 장비·부품은 안 떨어지고, 레벨도 안 내려가요. 잡은 사람은 보상이 거의 없어요. 반대로 3레벨 이상 높은 사람을 잡으면 **역전 보너스 ×1.5**.
- **몬스터 레벨 맞춤**: 몬스터는 무작위 학생 한 명 근처(13~28m)에 그 학생 레벨에 맞는 종류로 생겨요 → 낮은 레벨 근처엔 약한 몬스터.

## 3-4. 🌪 돌풍 발전기 (2026-10-15)

- 섬의 **풍력발전기 6기**(가운데에서 38m, 미니맵 청록 동그라미)가 돌풍 발전기예요. 청록 원 안에서 `E` 또는 [🌪 발전기 돌리기].
- **풍력 문제**(옥정섬 SOS 퀘스트·지식 카드 내용 41문제 중 무작위, 4지선다, **15초**)가 나와요. 숫자키 1~4로도 답할 수 있어요.
  - 맞히면: 경험치(레벨의 35%, 따라잡기 부스트 적용) + 10코인 → **8초 안에 돌풍 방향**(화면 기준 8방향, 안 고르면 보는 쪽)을 골라요.
  - 틀리거나 시간이 끝나면: **체력 −20%**(이걸로 쓰러지진 않음) + 정답 공개.
  - 문제 푸는 동안(방향 고를 때까지)은 **공격받지 않아요**(반투명 + '📘 문제 푸는 중' 이름표). 대신 공격·상점·과제·상자는 못 해요. 발전기에서 멀어지면 취소(15초 쿨).
  - **발전기 1기에 한 명만** 풀 수 있고, 한 번 돌리면(맞히든 틀리든) **60초 쿨타임** → 친구들과 돌아가며.
- **돌풍 12초**: 고른 방향으로 길이 26m·폭 9m 바람길(바닥에 하늘색 길 + 흰 바람 줄기, 미니맵에도 표시)이 생겨요.
  - 바람길 안의 상대는 바람 방향으로 밀려요(앞으로 걷기 힘듦, 가만히 있으면 밀려남). 돌린 사람·같은 팀·건물 위·보호 중인 사람은 안 밀려요.
  - **바람 화살**이 0.65초마다 바람길을 따라 날아가 맞으면 피해(12 + 돌린 사람 레벨×1.5). 몬스터도 맞고 밀려요.
  - 2부 협동 아레나에서는 친구는 안 밀리고 **몬스터만** 밀리고 맞아요.

## 3-5. 몬스터 레벨 · 스모그 늑대 (2026-10-15)

- **몬스터 레벨**: 몬스터는 무작위 학생 한 명 근처에 생기고, 그 학생 레벨 −1 ~ +2 레벨로 나와요(최대 Lv 18). 1레벨 오를 때마다 체력 +22%, 공격 +12%, 속도 +2%, 경험치·코인 +18%. 크기도 조금씩 커져요.
  - **25%는 원래 레벨 그대로**(약한 몬스터) → 늦게 온 친구도 사냥할 수 있어요.
  - 이름표에 `Lv` 표시: 나보다 3레벨 이상 높으면 **빨강**, 1~2 높으면 **주황**, 5레벨 이상 낮으면 회색.
- **🐺 스모그 늑대**(Lv 3~): **아주 빠름**(학생보다 조금 빠르고 레벨 따라 더 빨라짐), 2마리씩 다니며 **물고 빠졌다가 다시 달려듦**. 멀리서도 알아챔(22m). 미니맵 빨간 점.

## 3-6. 직업 전용 스킬 · 상성 (2026-10-15)

전직하면 **1번(질주)·3번(돌풍 대포)·6번(낙뢰)** 자리가 직업 스킬로 바뀌어요(버튼이 파란색). 나머지(바람 펀치·회오리·재충전·바람 방패·토네이도)는 공통.
스킬은 **보는 방향**으로 나가요(보는 쪽 ±30° 안의 적은 살짝 겨눠 줌) → 방향을 잘 잡는 게 실력.

| 직업 | 1번 | 3번 | 6번 |
|---|---|---|---|
| 🗡 바람 검사 | 돌진 베기: 7m 돌진, 처음 부딪힌 적 피해 + 0.8초 기절 | 대지 가르기: 앞 7m 일직선 피해 + 2초 둔화 | 대지의 분노: 뛰어올라 내려찍기, 주변 큰 피해 + 1초 기절 |
| 🏹 돌풍 궁수 | 구르기: 움직이는 쪽(가만히 있으면 뒤로) 5m, 구르는 동안 무적 | 관통 화살: 18m 꿰뚫음, 피해 + 둔화 | 화살비: 0.9초 뒤 지점에 3번, 피해 + 둔화(빨간 원 보고 피할 수 있음) |
| 🔮 번개 마법사 | 점멸: 6.5m 순간이동 | 바람 속박: 14m 구슬, 피해 + 1.5초 묶기 | 번개 폭풍: 0.6초 뒤 내 주변 6.5m 큰 피해 + 0.6초 기절 |
| 💚 치유 정령사 | 치유의 바람: 나·주변 친구 25% 회복 + 기절·묶기·둔화 풀기 | 생명 흡수 구슬: 15m, 피해 + 둔화, 준 피해 60% 회복 | 수호의 바람: 나·주변 친구 4초 보호막(피해 −60%) + 기절·둔화 면역 |

- **상성**: 검사 → 궁수 → 마법사 → 검사 (화살표 쪽에게 **피해 +20%**, '상성 +20%' 글씨). 치유 정령사는 상성 없이 친구를 지켜 줌.
- 기절: 못 움직이고 스킬도 못 씀(💫). 묶기: 못 움직이지만 공격은 됨(⛓). 둔화: 느려짐(🐌). 기절·묶기가 끝나면 1.5초 동안 다시 안 걸림(연속 기절 방지).
- 몬스터에게도 기절·묶기·둔화가 걸려요(보스는 약한 둔화만).

## 6. 참고

- 학생 이름·기록은 서버 메모리에만 있고 파일로 저장하지 않습니다. 서버를 끄면 모두 사라집니다.
- 그래픽: 하늘·구름·물결·풀꽃·그림자·둥근 캐릭터(옥정섬 SOS와 같은 스타일). 느린 태블릿은 시작 5초 뒤 자동으로 '가볍게'(그림자·풀 끔), 순위(Tab) 창에서 직접 바꿀 수도 있음.
