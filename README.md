# 옥정섬 SOS · 클리어 아레나 (교실용 실시간 대전 서버)

옥정섬 SOS를 클리어한 학생들이 한 섬에 모여 몬스터를 잡고 서로 겨루는 실시간 대전입니다.
서버(이 폴더)는 **선생님 컴퓨터**나 **무료 클라우드**에서 실행하고, 학생은 태블릿 브라우저로 접속합니다.
필요한 것은 Node.js 하나뿐이며, `npm install`은 하지 않아도 됩니다.

## 1. 선생님 컴퓨터에서 실행하기 (같은 와이파이)

1. Node.js 준비
   - 설치할 수 있으면: https://nodejs.org 에서 **LTS** 버전을 설치합니다.
   - 설치 권한이 없으면: 같은 사이트의 **Windows Binary (.zip)** 를 받아 압축을 풀고, 그 안의 `node.exe`를 이 폴더(server.js 옆)에 복사합니다.
2. 이 폴더의 **`start-windows.bat`** 을 더블클릭합니다. (맥: `start-mac.command`)
   - Windows 방화벽 창이 뜨면 **허용**(개인 네트워크)을 누릅니다.
3. 검은 창에 나온 내용을 확인합니다.
   - `학생 접속 주소` 예: `http://192.168.0.10:3000`
   - `관리자 비밀번호` 예: `a1b2c3`
4. 교실 TV(선생님 컴퓨터) 브라우저에서 `학생 접속 주소/admin` 을 열고 비밀번호를 넣으면 **실시간 순위판·관리 화면**이 나옵니다.
5. 끝나면 검은 창을 닫거나 `Ctrl + C`.

> 수업 전에 태블릿 한 대로 학생 접속 주소가 열리는지 꼭 확인하세요.
> 학교 무선망은 기기끼리의 통신을 막아 두는 경우가 있습니다(교사 PC가 유선망이거나 '클라이언트 격리'가 켜진 경우).
> 열리지 않으면 ① 선생님 노트북을 학생과 같은 와이파이에 연결하거나, ② 휴대용 공유기/핫스팟을 쓰거나, ③ 아래 클라우드 방법을 쓰세요.

## 2. 무료 클라우드에 올리기 (어디서나 접속)

Render(https://render.com) 예시:
1. 이 폴더를 GitHub 저장소로 올립니다.
2. Render → New → **Web Service** → 저장소 선택.
3. Runtime: Node · Build Command: 비워 두기 · Start Command: `node server.js`
4. Environment에 `ADMIN_KEY` = 원하는 관리자 비밀번호를 추가합니다.
5. 배포가 끝나면 `https://○○○.onrender.com` 이 학생 접속 주소, 뒤에 `/admin` 이 관리 화면입니다.
- 무료 요금제는 한동안 접속이 없으면 잠들어서, 첫 접속에 1분 정도 걸릴 수 있습니다. 수업 시작 전에 한 번 열어 두세요.

## 3. 옥정섬 SOS 게임과 연결하기

게임 링크 끝에 아레나 주소를 붙여 학생에게 나눠 주면, 클리어 화면에 **[클리어 아레나 입장]** 버튼이 생깁니다.

```
…게임 링크…#few&arena=192.168.0.10:3000
…게임 링크…#arena=https://○○○.onrender.com
```
(몬스터 설정이 없으면 `#arena=…` 만 써도 됩니다. 게임의 도움말 → '아레나 주소' 칸에 직접 적어도 됩니다.)

버튼이 없어도 학생은 TV에 띄운 주소로 들어가 **클리어 화면의 이름과 입장 코드(4자리)** 를 적으면 됩니다.
코드는 이름과 날짜로 만들어져서, 게임을 클리어한 학생만 알 수 있습니다. 관리 화면에서 코드 확인을 끄면 누구나 들어올 수 있습니다.

## 3-1. 아레나 두 개 (1부 대결 / 2부 협동)

| 아레나 | 학생 주소 | TV 관리 화면 | 입장 코드 | 내용 |
|---|---|---|---|---|
| **1부 대결** | `주소/` | `주소/admin` | 1부 CLEAR 화면의 코드 | 원래 방식: 개인전 PvP(팀전은 관리 화면에서 켤 수 있음), 왕관·현상금, 상점. 접속자 절반이 Lv 10 이상이면 레이드 보스 등장 |
| **2부 협동** | `주소/2` | `주소/admin2` | 2부 CLEAR(ALL CLEAR) 화면의 코드 (1부 코드와 다름) | 모두가 한편(서로 공격 안 됨), 4팀은 점수로만 경쟁. 협동 퀘스트 ① 발전기 수리(과제 기계, 인원×2) → ② 매연 정화(몬스터, 인원×4) → ③ 레이드 보스 토벌 → 🎉 완전 복구 |

- 두 아레나는 같은 서버에서 따로 돌아가요(기록·몬스터·보스 따로).
- **선생님(운영자) 입장**: 입장 코드 칸에 관리자 비밀번호(ADMIN_KEY)를 넣으면 날짜와 상관없이 들어가고 **Lv 100 운영자**가 돼요(최고 장비, 9999코인, 부품 99, 이름표 🛡 운영자). 학생 순위·왕관·보스 체력·퀘스트 목표 계산에서는 빠지고, 쓰러져도 잃는 것이 없어요. 이동 속도는 Lv 15 기준(+15%).
- 레이드 보스 **태풍 마수 돌개**: 체력 5000 + 9000×접속 인원. 내려찍기(근접), 빨간 원(1.3초 뒤 큰 회오리 + 밀쳐내기), 노란 원(1.4초 뒤 여러 명에게 낙뢰), 체력 60%·30%에서 부하 소환, 30% 아래 분노(더 빠름). 쓰러뜨리면 공격한 모두가 기여도만큼 코인 + 레벨 업(2부는 부품 ⚙3). 관리 화면 [태풍 마수 돌개 소환]으로 언제든 부를 수 있음.
- 몬스터 10종: 매연 달팽이 · 스모그 슬라임 · 미세먼지 벌 · 매연 멧돼지(돌진) · 스모그 골렘 + **회오리 족제비**(아주 빠르게 휙 돌진) · **매연 대포꽃**(멀리서 매연탄을 쏨) · **녹슨 집게게**(받는 피해 40% 감소) · **연기 박쥐**(3마리씩 떼로) · **강철 매연거북**(느리지만 노란 원 1초 뒤 한 방 48). 최대 레벨 15.

## 3-2. 섬 구조물 · 상점 4곳 · 전직 · 타격감 · 보물 상자 · 바다 낙사 (2026-10-15)

- **올라갈 수 있는 곳**: 전망대(높이 5, 계단+사다리) · 정비 데크(3.2, 계단+사다리) · 바위 고원(2.6, 경사로+사다리) · 감시탑(6.5, 사다리만) · 컨테이너(2.6 → 사다리로 높은 컨테이너 5.2). 계단·사다리 쪽으로 걸어가면 올라가고, 가장자리 밖으로 걸으면 뛰어내려요.
  - 높이가 다르면 **근접 공격(바람 펀치·회오리·몬스터 물기·거북 내려찍기)이 닿지 않아요** → 도망칠 수 있어요.
  - 날아다니는 몬스터(벌·박쥐)와 **원거리 공격(돌풍 대포·낙뢰·토네이도·대포꽃 매연탄·궁수 화살·보스 낙뢰)** 은 높이와 상관없이 맞아요. 보스의 빨간 원(회오리 강타)은 땅에 있는 사람만 맞아요.
- **몬스터 4배(2026-10-15 한 번 더 2배)**: 동시에 최대 110마리(8 + 접속 인원×5.6), 0.35초마다 생겨요. 통신량이 늘지 않게 학생 화면에는 **40m 안 몬스터만** 자세히 보내고, 먼 몬스터는 미니맵 점으로만 보여요. 수를 바꾸려면 Render Environment에 `MON_CAP`(최대 수)·`MON_PER`(학생 1명당) 값을 넣으면 돼요.
- **바람상회 4곳**: 동(33, 0) · 서 · 남 · 북. 노란 원(반지름 5.5) 안에서 `B`. 미니맵 노란 네모.
- **바람의 신전(섬 가운데)**: Lv 5부터 `J`로 **전직**(처음 무료, 바꾸면 100코인).
  - 🗡 바람 검사: 체력 +30%, 받는 피해 −10%, 바람 펀치 +30%, 세게 밀쳐냄, 덜 밀림
  - 🏹 돌풍 궁수: 바람 펀치가 9m 날아가는 화살, 이동 속도 +8%
  - 🔮 번개 마법사: 스킬 피해 +35%, 스킬 대기 −15%, 체력 −10%
  - 💚 치유 정령사: 재충전(스킬 4)이 주변 7m 친구(같은 팀·2부는 모두)도 30% 회복, 체력 회복 2배, 펀치 −10%
- **타격감**: 맞으면 뒤로 밀려요(멧돼지·골렘·거북·보스는 더 세게, 건물 벽은 통과 못 함). 맞은 대상이 번쩍이고, 큰 피해 숫자는 노랗고 크게, 내가 맞으면 화면이 흔들려요. 몬스터는 맞으면 잠깐 멈칫해요.
- **🎁 보물 상자 이벤트**: 2분 30초마다(첫 상자는 45초 뒤) 섬 어딘가에 빛기둥과 함께 상자가 떨어져요(35%는 건물 꼭대기). 미니맵에 금색 별. 떨어진 뒤 60초 안에 열지 않으면 사라져요.
  - 상자 옆에서 `E`(또는 [상자 열기])를 누르고 **3초 버티기**. 그동안 맞거나 멀어지면 끊겨요 → 다른 팀이 방해하러 몰려듦. 한 번에 한 명만 열 수 있어요.
  - 보상: 코인 90~150 · 아직 최고가 아닌 장비 하나 +1단계 · 회복 음료 +1 · 체력 가득(2부는 부품 ⚙3 추가). 섬 전체에 누가 열었는지 알려줘요.
  - 관리 화면 **[🎁 보물 상자 떨어뜨리기]** 로 선생님이 바로 떨어뜨릴 수도 있어요.
- **🌊 바다로 밀어 떨어뜨리기**: 섬 가장자리 해변(가운데에서 55m 바깥)에서 맞으면 1.8배 더 멀리 밀리고, 바다까지 밀리면 풍덩!
  - 1부: 바다에 빠지면 쓰러짐(민 사람이 처치한 것으로, 6초 안에 때린 사람이 있으면 그 사람). 2부: 섬으로 건져 올리고 체력 −25%만.
  - 몬스터(벌·박쥐 제외)도 바다로 밀면 바로 정화 + 보상. 처음 해변에 들어가면 안내가 한 번 떠요.

## 4. 규칙 요약

| 항목 | 내용 |
|---|---|
| 기본 | 섬 어디서나 몬스터 사냥과 학생끼리 대결이 가능. 부활 직후 3초는 보호(공격하면 풀림) |
| 쓰러지면 | 5초 뒤 무작위 위치에서 부활. **코인 30%** 와 **가장 좋은 장비 1단계**를 그 자리에 떨어뜨림(다른 사람이 주울 수 있음). 경험치 40% 감소 → **레벨이 내려갈 수 있음** |
| 순위 | 레벨 → 경험치 → 코인 순. 1등(Lv 3 이상, 2등보다 앞설 때)은 **👑 왕관과 현상금** |
| 현상금 | 30 + 레벨×6 + 연속 처치×15 코인. 1등이 쓰러지면 **최근 12초 동안 1등을 공격한 모두가 나눠 가짐** → 함께 1등을 잡도록 유도 |
| 팀전 | 입장하면 인원이 적은 팀에 자동 배정되는 **4개 팀**(바람·태양·바다·번개). 같은 팀은 서로 공격되지 않음. 관리 화면에서 팀 다시 나누기·팀전 끄기 가능 |
| 과제 (어몽어스식) | 섬 곳곳 **과제 기계 8곳**(미니맵의 청록 마름모, 머리 위 `!`). 가까이 가서 `E` 또는 [과제 하기]. 전선 연결 · 나셀 돌리기 · 부품 순서 · 바람 퀴즈. 성공하면 경험치(레벨의 40%)·12코인·**팀 게이지 +1**, 같은 기계는 45초 뒤 다시. 틀리면 8초 대기. 하는 도중 공격받거나 기계를 떠나면 취소(이름 앞에 ⚙ 표시가 떠서 다른 팀이 노릴 수 있음) |
| 팀 레벨 업 · 바람의 축복 | 팀 게이지(4 + 팀 인원×3)가 가득 차면 **그 팀 모두 +1 레벨** + **60초 바람의 축복**(공격 +30%, 받는 피해 −20%, 속도 +10%, 몸에 팀 색 빛) |
| 부품 ⚙ | 과제 성공마다 1개(과제는 체력 25%도 회복). **좋은 장비는 부품이 필요**: 무기·갑옷 2단계 ⚙1 · 3단계 ⚙3 · 4단계 ⚙5, 신발·모자 2단계 ⚙1 · 3단계 ⚙2. 쓰러지면 부품 1개를 떨어뜨림 |
| 팀 점수 | 과제 ×3 + 처치 ×1 + 팀 레벨 업 ×10. 결승 라운드가 끝나면 **1위 팀 발표** |
| 상점 | 동·서·남·북 **바람상회** 4곳(노란 원 안)에서 `B` 또는 [상점] 버튼. 원하는 단계를 바로 구매. 싸우는 중(4초)에는 불가. 코인을 쓰면 순위(코인)가 내려갈 수 있음 |
| 장비 | 무기 4단계(공격 +5씩, 60/150/280/450) · 갑옷 4단계(체력 +22·피해 −6%씩, 60/150/280/450) · 신발 3단계(이동 속도 +7%씩, 50/120/220) · 모자 3단계(스킬 대기 −8%씩, 50/120/220). 몬스터도 가끔 떨어뜨림 |
| 회복 음료 | 상점에서 25코인, 최대 3개(입장 때 1개). `R` 또는 [음료] 버튼, 체력 45% 회복, 싸우는 중에도 사용 가능(4초 간격) |
| 스킬 | Lv1 바람 펀치(Space) · Lv2 질주(1) · Lv3 회오리(2) · Lv4 돌풍 대포(3) · Lv5 재충전(4) · Lv6 바람 방패(5) · Lv7 낙뢰(6) · Lv8 토네이도(7) |
| 결승 라운드 | 관리 화면에서 5~15분 선택 → 모두 Lv 1로 다시 시작. 마지막 40%(최대 2분 30초) 동안 **바람의 벽**이 섬 가운데로 좁혀지고 밖에 있으면 계속 피해. 끝나면 학생 화면에 시상대 |
| 말풍선 | `T` 또는 버튼: 정해진 6개 문구만(채팅 없음) |

## 5. 관리 화면에서 할 수 있는 것

- 실시간 순위(TV용 큰 글씨), 섬 지도에 학생 위치
- 결승 라운드 시작/종료, 자유 대전으로 돌리기, 모두 초기화
- 입장 코드 확인 켜기/끄기, 이름으로 오늘의 코드 찾기
- 학생 퇴장(내보낸 학생 화면은 입장 화면으로 돌아가고 자동으로 다시 들어오지 않아요)
- **🚪 수업 끝 · 모두 내보내기**: 선생님(운영자)을 뺀 모두를 내보내고 **입장을 잠가요**. 다음 수업 때 [🔒 입장 잠그기] 체크를 풀면 다시 열려요.
- 창을 안 닫고 둔 학생은 **5분 동안 조작이 없으면 자동으로** 나가요.
- 보물 상자 바로 떨어뜨리기

## 6. 참고

- 학생 이름·기록은 서버 메모리에만 있고 파일로 저장하지 않습니다. 서버를 끄면 모두 사라집니다.
- 그래픽: 하늘·구름·물결·풀꽃·그림자·둥근 캐릭터(옥정섬 SOS와 같은 스타일). 느린 태블릿은 시작 5초 뒤 자동으로 '가볍게'(그림자·풀 끔), 순위(Tab) 창에서 직접 바꿀 수도 있음.
- 최대 40명. 30명 동시 접속 시험에서 학생 1명당 초당 약 20KB를 주고받았습니다(30명 ≈ 5Mbps).
- 접속이 잠깐 끊겨도 3분 안에 같은 태블릿으로 다시 들어오면 레벨·코인이 그대로 이어집니다.
- 포트를 바꾸려면 `PORT=4000 node server.js` (윈도우는 start-windows.bat 의 `set PORT=` 줄을 고치기).
